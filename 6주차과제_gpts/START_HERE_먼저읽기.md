# Data Chef AI · 여기부터 시작하세요

**현재 버전은 한 개의 완성된 Streamlit 프로젝트입니다. `gpt-6-luna` 모델을 사용하도록 고정했습니다.**

기능: 식재료 수량 입력 → GPT-6 Luna의 새 레시피 후보 생성 → Python 기반 100점 추천·영양 계산·차트. 냉장고 사진 판독 및 포장 식품 성분표 판독도 포함합니다. 기본 레시피 체험은 API 키 없이 작동합니다.

## A. 인터넷에 바로 띄우기 (발표용 권장)

1. [GitHub 새 저장소](https://github.com/new)에서 `data-chef-ai`라는 저장소를 만듭니다. ZIP을 압축 해제해서 나온 파일을 **그대로 모두** 저장소에 업로드하세요. **ZIP 파일 자체를 올리지 마세요.** 저장소 첫 화면에 `app.py`와 `requirements.txt`가 바로 보여야 합니다. 숨긴 `.streamlit` 폴더도 업로드해 주세요. **`secrets.toml`은 업로드하지 마세요.**
2. [Streamlit Community Cloud](https://share.streamlit.io/) → `Create app`에서 방금 만든 GitHub 저장소를 선택합니다. **Main file path = `app.py`, Branch = `main`**.
3. **Advanced settings → Secrets**에 아래 형식으로 실제 API 키와 자신이 정한 비공개 접근 코드를 넣습니다:

   ```toml
   OPENAI_API_KEY = "sk-여기에_실제_발급한_키"
   APP_ACCESS_CODE = "여기에_직접_정한_비공개_접근_코드"
   ```

   [API 키 발급](https://platform.openai.com/api-keys) · [Streamlit Secrets 공식 안내](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/secrets-management)

4. **Deploy**를 클릭합니다. 생성된 `.streamlit.app` URL로 접속해서 접근 코드를 입력하고 레시피 추천을 누르면 됩니다.

API 키는 ChatGPT Plus 구독과 별도의 유료 API 계정 키입니다. 대신 넣어줄 수 없으며, **키를 공개 저장소에 넣으면 안 됩니다.** `APP_ACCESS_CODE`는 발표용 웹앱의 과도한 API 사용을 막기 위해 권장합니다.

## B. GitHub 없이 내 컴퓨터에서 실행

Windows에서 폴더 안의 `run_windows.bat` 파일을 더블 클릭합니다. 또는 터미널에서 다음을 실행합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저 주소: `http://localhost:8501`. 사이드바의 `API 키 (로컬 테스트용)`에 발급받은 키를 입력하면 루나를 사용할 수 있습니다. **키가 없어도 기본 레시피, 점수 계산, 영양 레이더는 실행됩니다.**

## C. 웹에서 시험할 예시

- 레시피 추천: `계란 2개, 두부 반 모, 양파 1개, 시금치 100g, 식용유 10g` → 목표 `고단백` → `루나가 새로운 레시피 후보 4개를 직접 만들기` 체크 → 추천 시작
- 알레르기 필터: 위 입력에서 `난류` 제외 → 달걀이 들어 있는 후보가 제거되었는지 확인
- 냉장고 사진: `📸 냉장고 사진` → 사진 업로드 → 재료 인식 → 수량 수정 → 첫 탭으로 돌아가 추천
- 성분표 사진: `🔎 성분표 분석` → 선명한 제품 뒷면 사진 업로드 → 숫자·기준량·원재료명·알레르기 표시 확인
- 알고리즘 실습: `가중치 조정`에서 `재료 활용` 비중을 높이고 순위/점수가 달라지는지 확인

## D. 꼭 알아두기

- **루나 고정:** 코드를 수정하거나 모델명을 따로 입력할 필요가 없습니다.
- **영양 데이터:** 기본 포함 데이터는 수업용 근사값(공식 DB 원본 아님)입니다. 개인별 치료 식단 판정용이 아닙니다. `📊 데이터 / 알고리즘`에서 100g 기준 공식 CSV를 적용할 수 있습니다.
- **재료 범위:** 기본 데이터에 등록된 56가지 재료 위주로 검증하며, 없는 식재료는 자동으로 영양 수치를 지어내지 않습니다.
- **알레르기:** 앱의 알레르겐 분류는 제한적인 실습용 매핑입니다. 실제 라벨·교차접촉 위험은 반드시 직접 확인해야 합니다.
- **사진 분석:** AI가 글씨나 물체를 잘못 인식할 수 있습니다. 추출 결과의 불명확한 부분은 원본 사진과 대조하세요.
- **API 오류:** 키, 과금 크레딧, 네트워크, 사용량 제한에 따라 실제 호출에 실패할 수 있습니다. 이 경우 기본 추천으로 자동 전환합니다.
- **검증:** API 응답 형식과 계산 로직은 로컬 모의 테스트로 확인했으며, 이 생성 환경에 Streamlit 설치 및 실제 API 자격증명이 없어 인터넷 배포/실 API 실사용은 최종 검증하지 못했습니다.
